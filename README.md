# Scientific Calculator

## Description
A simple scientific calculator built using Python and Tkinter. It has a dark-themed graphical interface and supports basic arithmetic and scientific calculations.

## Features
- Basic operations: Addition, Subtraction, Multiplication, Division.
- Scientific functions: sin, cos, tan, log, ln, and square root.
- Trigonometric calculations in Degrees and Radians.
- Memory functions (MC, MR, M+, M−).
- Factorial, powers, and percentage.
- Keyboard support.
- Safe expression evaluation.

## Requirements
- Python 3.x
- Tkinter (usually included with Python)

No external libraries are required.

## How to Run

1. Save the code as `scientific_calculator.py`.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python scientific_calculator.py
```
